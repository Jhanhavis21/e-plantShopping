# 🌿 Paradise Nursery (React + Redux Project)

## 📌 Description
Paradise Nursery is an online plant shopping application built using React and Redux. It allows users to browse plants, add them to a cart, and manage their shopping cart dynamically.

## 🚀 Features
- Landing page with background image
- Product listing with 6 plants
- Categorized plants (Indoor, Succulent, Flowering)
- Add to Cart functionality
- Cart icon updates dynamically
- Increase / Decrease quantity
- Remove items from cart
- Total cost calculation
- Continue shopping option
- Checkout (Coming Soon)

## 🛠️ Technologies Used
- React.js
- Redux Toolkit
- CSS

## 📂 Project Structure
- App.jsx
- ProductList.jsx
- CartItem.jsx
- CartSlice.jsx
